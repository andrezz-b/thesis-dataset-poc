# <Name>

Image QA over Wikidata: an **image of <thing>** plus the question *"<question>"*, answered by walking the Wikidata graph.

| Image | Question | Path | Answer |
|---|---|---|---|
| <Label> (<QID>) | <question> | `<hop> (<P1>) → <hop> (<P2>)` | **<answer>** (<intermediate>, <Q>) |

The goal: determine the entity from an image (embedding search), then follow the graph to the answer.
Back to the [top-level README](../../README.md).

## Layout

```
index.js            standard example export: meta + entities()
src/gold.js         gold SPARQL and gold entity (label, preferred-rank P18 image, answer)
src/expand.js       SPARQL expansion: unambiguous same-class entities -> distractors
images/             512px Commons thumbnails, named <QID>_<file> (committed)
query/              test query image (committed)
dist/               generated and gitignored: entities.json, gold_result.json, *_raw.json, e2e.json
```

## Running

```bash
mise run all <id>        # vector:up + build + index + e2e + docs
```
