# Egg Chair Designer Birth Year Example

Image QA over Wikidata: an **image of a chair** plus the question *"In which year was the designer of this chair born?"*,
answered by walking the Wikidata graph.

| Image | Question | Path | Answer |
|---|---|---|---|
| Egg chair (Q1301042) | In which year was the designer of this chair born? | `designed by (P287) → date of birth (P569)` | **1902** (Arne Jacobsen, Q273572) |

The goal: determine the chair entity from an image (embedding search), then follow the graph to the designer
and their birth year. Back to the [top-level README](../../README.md).

## Layout

```
index.js            standard example export: meta (name, description, question, gold query, query image) + entities()
src/gold.js         gold SPARQL for the Egg chair and the gold entity (label, preferred-rank P18 image, answer)
src/expand.js       SPARQL expansion: chairs with an unambiguous answer -> distractor entities
images/             512px Commons thumbnails, named <QID>_<file> (committed)
query/              test query image (committed)
dist/               generated and gitignored: entities.json, gold_result.json, chairs_raw.json, e2e.json
```

## Running

```bash
mise run vector:up
mise run build egg-chair
mise run index egg-chair
mise run e2e egg-chair
mise run docs
mise run all egg-chair
```

## Gold query (`src/gold.js`)

Result (`dist/gold_result.json`): Arne Jacobsen (Q273572), born `1902-02-11` → **1902**.

## Image

The Egg chair has a single P18 image (`The Egg Chair.jpg`), which is indexed. The query image is a different Commons
photo from the entity's Commons category (`Egg chair - Arne Jacobsen (1958).jpg`), so the match is not trivial.

## Expansion (`src/expand.js`)

The gold has no `P31`; it is `P279 wd:Q15026` ("chair"), so the class is items with `P279 wd:Q15026`. Group by chair,
drop those with several designers/birth dates or several images, drop unlabeled items, keep the first `IMAGE_COUNT`
by QID, plus the gold entity (26 entities by default). Ground truth (`designer`, `designerLabel`, `answer`) is kept in
`entities[].extra`, **not** in the vector index.

**Caveats:**
- The gold's English label is just "Egg".
- Other Arne Jacobsen chairs (Swan, Ant) are among the distractors and share the same answer; they are also visually
  close to the Egg chair, and the Egg chair does not rank first for the query image (see below).
