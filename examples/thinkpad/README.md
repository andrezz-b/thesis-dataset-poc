# IBM ThinkPad Manufacturer Inception Example

Image QA over Wikidata: an **image of a laptop** plus the question *"In which year was the manufacturer of this laptop established?"*,
answered by walking the Wikidata graph.

| Image | Question | Path | Answer |
|---|---|---|---|
| IBM ThinkPad 701 (Q106942963) | In which year was the manufacturer of this laptop established? | `manufacturer (P176) → inception (P571)` | **1911** (IBM, Q37156) |

The goal: determine the laptop entity from an image (embedding search), then follow the graph to the manufacturer
and its inception year. Back to the [top-level README](../../README.md).

## Layout

```
index.js            standard example export: meta (name, description, question, gold query, query image) + entities()
src/gold.js         gold SPARQL for the ThinkPad 701 and the gold entity (label, preferred-rank P18 image, answer)
src/expand.js       SPARQL expansion: laptop models with an unambiguous answer -> distractor entities
images/             512px Commons thumbnails, named <QID>_<file> (committed)
query/              test query image (committed)
dist/               generated and gitignored: entities.json, gold_result.json, laptops_raw.json, e2e.json
```

## Running

```bash
mise run vector:up
mise run build thinkpad
mise run index thinkpad
mise run e2e thinkpad
mise run docs
mise run all thinkpad
```

## Gold query (`src/gold.js`)

Result (`dist/gold_result.json`): IBM (Q37156), inception `1911-06-16` → **1911**.

## Image

The ThinkPad 701 has a single P18 image (`Thinkpad 701.jpg`), which is indexed. The query image is a different Commons
photo (`IBM ThinkPad 701 Butterfly 05.JPG`, showing the butterfly keyboard), so the match is not trivial.

## Expansion (`src/expand.js`)

Class `P31 wd:Q73343954` ("laptop model"). Group by laptop, drop those with several manufacturers/inception values or
several images, drop unlabeled items, keep the first `IMAGE_COUNT` by QID, plus the gold entity (26 entities by default).
Ground truth (`manufacturer`, `manufacturerLabel`, `answer`) is kept in `entities[].extra`, **not** in the vector index.

**Caveat:** by QID order the distractors skew towards recent System76 models, so many are near-duplicates of each other.
